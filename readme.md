# ORB Feature Matching with OpenCV

This project demonstrates how to use OpenCV's ORB (Oriented FAST and Rotated BRIEF) algorithm for feature matching between two images. ORB is a fast, robust, and efficient algorithm suitable for applications like object recognition and tracking. In this example, we load two images, detect their keypoints and descriptors, and then match these features using the BFMatcher (Brute Force Matcher) algorithm.

- OpenCV (`cv2`)
